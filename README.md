# 90801: Titanic Exploratory Data Analysis (EDA)

This repository contains data files and Jupyter Notebook solution keys for exploratory data analysis (EDA) exercises centered on Titanic passenger demographics, luggage records, and dining expenses.

## Repository Contents

### Notebooks
- `02_titanic_eda_answer_key.ipynb` — Answer key covering fundamental exploratory data analysis and data manipulation.
- `03_EDA_in_class_answer_key.ipynb` — In-class answer key detailing advanced data cleaning, joining/merging datasets, and statistical summaries.

### Datasets
- `datafiles-titanic.csv` — Primary Titanic passenger demographics and survival data.
- `titanic_luggage.csv` — Records of passenger luggage counts and baggage details.
- `titanic_restaurant.csv` — Records of passenger dining charges and onboard restaurant expenditures.
